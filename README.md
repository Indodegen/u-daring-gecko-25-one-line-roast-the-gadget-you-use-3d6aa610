# One-Line Roast: The Gadget You Use Every Day

Entry for make.fun bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610` ($5 pot, top 3 paid).

One original line, up to 200 characters, roasting a gadget used every day. `main.ts` copies `entry.txt` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).

> My phone unlocks for my cat, my reflection in the toaster, and everyone except me before coffee.
